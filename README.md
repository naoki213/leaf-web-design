# LEAF

ホームページ制作サービス「LEAF」のポートフォリオ兼広告サイトです。

制作料0円、10〜20ページ規模にも対応可能、公開後はご契約期間中月額2,000円固定というサービス内容を、Webサイトが完成していくスクロール体験で紹介します。

## 掲載内容

- 制作工程を模したHero UI
- Sticky形式の制作サンプル紹介
- 料金・サービス範囲
- 大型サイトのサイトマップ表現
- レスポンシブ対応・基本SEO・公開・修正対応の説明
- 公開後の更新イメージ
- 制作フロー、限定募集、FAQ、相談CTA

制作サンプルとして、公開中の KASANE、nue、NICO、NORTH をトップページ内のブラウザ表示と外部リンクで掲載しています。

ドメイン・サーバー・修正回数・解約・ネットショップなどの個別条件は未確定のため、サイト内では相談ベースの表現に留めています。
